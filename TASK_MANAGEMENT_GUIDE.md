# Task Management Guide

Statuses: Not Started, Ready, In Progress, Blocked, In Review, Completed, Deferred.

Priorities: Critical, High, Medium, Low.

Development categories: Business Analysis, Architecture, Database, Backend, Frontend, Integration, Testing, Deployment, Documentation.

Use task dependencies to prevent work from being treated as actionable before prerequisites are complete. Record acceptance criteria, estimate, actual effort and technical notes. Export JSON backups regularly; LocalStorage does not sync to GitHub.
